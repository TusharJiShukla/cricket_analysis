## 🚀 About The Project

The **Cricket Analytics** repository represents a massive data mining and analytical undertaking. By aggregating and dissecting historical match data across multiple World Cup cycles (2007, 2011, 2015, 2019, 2023), this project identifies macro-level trends in player performance, pitch degradation, and match outcomes.

---

## 🏗️ Methodology & Tech Stack

- **Primary Language**: Python.
- **Environment**: Jupyter Notebooks for interactive data exploration and visualization.
- **Data Manipulation**: `pandas` and `numpy` for massive dataset cleaning, merging, and aggregation.
- **Visualization**: `matplotlib` and `seaborn` for statistical plotting (heatmaps, scatter plots).

---

## ✨ Core Features

1. **Longitudinal Analysis**
   - The data is meticulously categorized by year to observe the evolution of the game over 15 years.
2. **Raw & Processed Datasets**
   - Contains both the raw CSV outputs and the thoroughly cleaned datasets used for final visualizations.
3. **Performance Metrics**
   - Calculates advanced metrics (strike rates, economy variations) rather than basic counting stats.
4. **Extensive Academic Documentation**
   - The repository includes a `Project summary.docx` detailing the exact statistical methodologies and ultimate conclusions derived from the data.

## 💻 Installation & Setup

### Prerequisites
- Python 3.8+
- Jupyter Notebook environment (or VS Code with Jupyter extensions).

### 1. Clone the repository
```bash
git clone https://github.com/TusharJiShukla/cricket_analysis.git
cd cricket_analysis
```

### 2. Setup Virtual Environment & Dependencies
```bash
python -m venv venv
source venv/bin/activate  # On Windows: .\venv\Scripts\activate
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Launch Notebooks
```bash
jupyter notebook
```
Navigate to any of the year-specific folders (e.g., `2011`, `2023`) to execute the analytical cells and reproduce the visualizations!
